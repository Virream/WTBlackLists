# WTRouteTester — 跑图线路测试器 · 功能与实现逻辑记录

> 对应当前代码(2026-10-07)。设计细节另见 [`跑图线路测试器.md`](跑图线路测试器.md),
> 8111 接口实测结论见 [`8111使用经验.md`](8111使用经验.md)。
> 本文档是**功能与状态总览**, 便于回顾"现在做到哪一步了"。

---

## 1. 用途

记录"重生后多久到达某位置"的独立小工具(与黑名单助手互不影响, 可单独运行)。

- 数据来源只有**游戏自带的 8111 本地 HTTP 接口**(纯读, 不碰游戏文件);
- 地图图片、玩家坐标、战区都从 8111 取; 关掉游戏后依旧能用**本地缓存**看回放;
- 一次跑图 = 一条线路记录; 支持多条对比、回放、按模式/版本分组。

启动: `python route_tester.py`;打包版 `WTRouteTester.exe`(见 §10)。

> **单实例**: 只允许运行一份 —— 重复启动不会开出第二个窗口, 而是把已有窗口调到前面
> (全屏游戏里抢不到焦点时闪任务栏) + 弹“程序已在运行中”。与黑名单主程序的单实例
> 互不影响, 两个程序可同时开。实现见 §12 `wt81111g/route_instance.py`。

## 2. 界面布局

| 区域 | 内容 |
|---|---|
| **左: 侧栏(全高)** | 四层树: 地图 → 模式 → 版本 → 线路; 列 = 展开/收起 / 地图·模式·版本·线路 / 信息; **统一背景 + 层级竖线**; **启动默认全部折叠**, 之后您展开/折叠的状态在侧栏重建后保持 |
| **右: 地图区** | 8111 地图图片 + 轨迹 + 起点/标记/终点 + 战区(菱形 A/B/C) + 重生位置(红/蓝空心方块) + 玩家位置(**圈 + 前方 `^` 标车头朝向**, 2026-10-11 新增); 支持缩放/平移; **鼠标悬停任意显示中的轨迹** → 左下角浮层显示「录制时刻 \| 车型 \| 用时」+「时间 \| 速度」, 并在命中点画白环 |
| **下: 信息区(172px)** | 第 0 行回放控制(▶ 回放 / ⏭ 到下一标记 / 倍速 / ■ 结束播放 / 基准与待回放提示) + 分割线 + 状态、采样间隔、载具/速度/计时/标记数、三个录制按钮(带绿圈/红圈/黄圈图标)、选项 |

**地图重绘性能**(2026-10-08): 重绘跟随采样率(默认 25Hz), 所以: 轨迹的**分桶几何按
0~1 归一化坐标缓存**(缩放/平移/改窗口都不用重算), 绘制时**平移/缩放的只是画笔**;
轨迹层渲进一张**带 35% 余量的离屏图**, 拖动时直接偏移贴图(一帧 1ms 量级);
回放用**累加层**(每帧只补新播放到的段); 128 个重生方块合成 `QPainterPath` 并缓存;
战区(会闪烁)/玩家/悬停每帧现画。实测 5 条真实线路(3766 点): 预览 41 → **1.2ms/帧**,
拖动 53 → **1.2ms/帧**, 回放 5 条 41 → 5.4ms。
Qt 6 的 `QPainter` 没有 GPU 后端(纯 CPU 光栅), 换成 OpenGL 自绘收益不成比例, 故只优化 CPU
工作量 —— 详见 `docs/跑图线路测试器.md` §5「绘制性能」。

**地图缩放质量**: 底图缩放用**平滑(双线性)滤波**(`SmoothPixmapTransform`), 放大后不再有
台阶/马赛克; 实测开销可忽略(整帧 1.72 → 1.49ms, zoom 3/8/20 一样)。另外**优先用最清晰的
那份底图**: 8111 有时只发 1024²(缓存里有 2048² 的同一张图), 以前直接画模糊的那份, 现在
`MapCache.sharpest()` 改用缓存里更清晰的(只读图片头比像素数); 放大 8 倍实测清晰度
2.69 → 3.73(+39%), 肉眼可见。剩下的唯一较大开销是**改缩放时重建轨迹层**(12~25ms, 只在
滚轮那一瞬间发生, 不跟手不影响拖动)。

> 界面上**不放常驻提示文字**(说明改到菜单「帮助 → 关于 / 功能说明…」,
> 正文在 `wt81111g/help_text.py`); 界面上只留真正在变的数值与状态。

## 3. 状态模型(最容易混淆的地方)

| 概念 | 含义 | 唯一来源 |
|---|---|---|
| **眼睛图标** | 该线路**是否画在地图上** | `RouteTesterWindow._visible_ids` |
| **选中(Shift/Ctrl)** | **回放播哪几条**; 选中的轨迹会用速度配色高亮 | 树的选中项 |
| **基准(图钉)** | 当前多选的"版本"; 多选锁死在该版本内 | `_anchor = (地图键, 战区指纹)` |
| **高亮层** | 选中的那几条里**眼睛已点亮的**用速度配色画在最上面 | `map_view._highlight` |
| **刚录制的那条** | 没选中任何条目时充当默认高亮(同样要求眼睛点亮) | `_last_record` |

规则要点:

- **显示只由眼睛决定**; 选中只负责"回放"与"把已显示的轨迹画得更醒目";
  眼睛没点亮的轨迹**不会**被高亮层画回去(否则点眼睛时该行恰好被选中, 看起来就像点了没反应);
- **同一版本才能共显/多选**(同一张图 + 同一战区布局) —— 不同交战区域的线路不可比;
- **双击线路 = 定基准 + 显示它 + 把底图切到它那张图**;基准版本行前面有**图钉**;
  没定过基准时, 第一个点到的线路即为基准;清空选中不清基准;
- 高亮层: 有选中 → 选中的那几条用速度配色;没选中 → 退回"刚录制的那条"(要求它眼睛仍点亮);
- **层级行(地图/模式/版本)不可被选中**(只可点击展开、右键、悬停)。

## 4. 录制

- 三个入口: 按钮 / 全局快捷键(默认 F5 / F6 / F7, 可在菜单里改) / (可选)"以速度从零变化时刻作为起始时间点";
- 采集: `/map_obj.json` 取玩家坐标(默认 40ms ≈ 25Hz, 可调 20–100ms)、`/indicators` 取载具与速度;
- **车头朝向**: 同一份 `/map_obj.json` 里玩家对象的 `dx`/`dy` 是**单位方向向量**(与 `/map.img`
  同坐标系), 直接拿它当朝向 —— 地图上玩家圈前方那个 `^` 就是按它转的(与游戏自带地图上的
  小三角一致)。角度用 `atan2(dy*h, dx*w)` 换算(用地图显示尺寸, 非正方地图才不会拉歪);
  拿不到 `dx`/`dy` 或向量全零时只画圈, 不画箭头;
- 起点=绿色圈, 标记=黄色圈(旁边标时间), 终点=红色圈;轨迹按速度着色(慢蓝 → 快红);
- **录制期间其余功能全部锁定**: 侧栏(眼睛/选中/右键)、回放按钮与倍速、采样间隔、选项,
  以及菜单里的「地图管理」「用缓存底图重新显示当前轨迹」;
- 开始录制时若正在预览**别的地图/版本**, 程序会**先切回游戏当前地图**、清掉预览点亮,
  并在状态栏说明 —— 避免"看着 A 图、录的是 B 图";
- 战局外(8111 只给 `"?"` 占位图)拒绝开始录制;等待移动期间结束录制 = 取消(不落盘)。

## 5. 地图与缓存

- 8111 **不提供地图名**(实测见 `8111使用经验.md` §3.6), 所以地图身份 = **`/map.img` 字节的 sha1 前 12 位**;
- 进入战局发现新图即写入 `<data>/maps/<指纹>.<jpg|png>`, 同一张图只存一次;战局外的 `"?"` 占位图不入缓存;
- 显示/回放某条线路时**底图自动切成它的地图**(游戏在跑用实时图, 否则用缓存图);
- 菜单「地图」→「地图管理…」: 缩略图/大小/轨迹数/首次缓存时间, 顶部固定输入框改名(回车即存),
  删除缓存图片, 打开缓存目录;
- 菜单「设置」→「显示战区位置(A/B/C)」: 地图上画战区小菱形(可开关, 记在 QSettings)。- 菜单「设置」→「显示重生位置(红/蓝方块)」: 地图上画重生候选位置(空心方块,
  红=敌方蓝=我方; 只画地面载具 —— 空军重生点的坐标不是 0~1 归一化), 同样可开关;
  重生位置跟战区布局一起按“地图 + 战区指纹”存进 `map_zones[].spawns`。

## 6. 模式与版本(2026-10-06 新增, 关键)

8111 不给模式名, 但 `/map_obj.json` 里每个战区都是 `capture_zone` 对象
(带 `zone_label` "A"/"B"/"C"、中心坐标、归属色、blink 标志):

| 战区数 | 模式 | 实测 |
|---|---|---|
| 3 | 战区控制 | ✅ |
| 2 | 战区攻陷 | ✅ |
| 1 | 战区争夺 | ✅ |

- **同一模式还有多个"版本"**: 控制/攻陷分大地图/小地图(交战区大小不同 → 战区位置不同),
  争夺的单战区从 3 个位置随机 → **模式 + 战区位置才是真正的比赛版本**;
- 侧栏因此是 **地图 → 模式 → 版本 → 线路** 四层;版本 = 战区**坐标指纹**;
- 版本自动命名: 多战区按**跨度**(战区间最大距离)降序 → `区域 1`(通常是大地图);
  单战区按坐标 → `点位 1/2/3`;右键版本行可改成"大地图/小地图"(`layout_names` 落盘);
- 领土归属实时刷新: 蓝 `#174DFF` = 我方, 红 `#fa0C00` = 敌方, 白 = 中立;
  被占领中(`blink>0`)按官方页面的脉冲曲线在本阵营色里做"变暗 ↔ 纯色"呼吸;
- 旧记录(没有战区字段)归"未知模式 → 未知位置";若轨迹带了指纹而 `map_zones` 没存过布局,
  会**从指纹反推**战区位置补上。

## 7. 回放

- 回放对象: 侧栏选中的线路(只限同一版本) → 没选中时依次退回"眼睛点亮的" → "刚录制的那条";
- 多条同时回放: 统一时间轴从 00:00 开始, **以最长的播完才结束**;每条各画一个回放光标;
- "⏭ 到下一标记暂停": 跨轨迹统一取**当前进度之后最近**的标记时刻;
- 倍速 0.5X–16X(32 档, 记住选择);回放期间其余功能同样锁定, 需点「■ 结束播放」返回;
- 已播放部分按速度着色, 未播放部分**半透明**(唯一使用半透明的地方)。

## 8. 持久化

`<data>/routes.json`(原子写: tmp + `os.replace`;读取容忍 BOM):

```json
{
  "version": 1,
  "map_names":   { "<地图指纹>": "美国·沙漠之城" },
  "layout_names": { "<地图指纹>": { "<战区指纹>": "大地图" } },
  "known_maps":  [ "<地图指纹>" ],
  "map_zones":   { "<地图指纹>": [ { "sig": "...", "count": 3, "mode": "战区控制",
                                     "zones": [ {"label":"A","x":0.43,"y":0.55} ],
                                     "seen_at": "..." } ] },
  "routes":      [ { "route_id": "...", "map_key": "...", "vehicle": "Leopard 2PL",
                     "duration": 97.3, "zone_count": 3, "zone_signature": "...",
                     "mode_name": "战区控制", "points": [...], "marks": [...] } ]
}
```

其它文件: `<data>/maps/`(地图图片缓存 + `index.json` 分辨率无关的内容指纹索引)、
`<data>/routes.json.bak`(合并重复地图前的备份)、`<data>/route_tester.log`(日志)。

> **地图身份**: 8111 会把同一张地图发成 1024²/2048²/4096² 等不同分辨率, 字节哈希因此不同 ——
> 所以身份用**内容指纹**(缩到 64×64 灰度比相似度, 阈值 4/255), 字节哈希只当文件名与
> 变化检测; 老版本造成的“同图两键”在启动时自动合并(见 `docs/跑图线路测试器.md` §3)。

## 9. 全局快捷键

| 动作 | 默认键 |
|---|---|
| 开始录制轨迹 | F5 |
| 结束录制轨迹 | F6 |
| 标记当前位置 | F7 |

**两条通道, 任意一条命中即触发**(同一动作 0.3s 内去重, 不会触发两次):

| 通道 | API | 特点 |
|---|---|---|
| 系统热键(主) | `RegisterHotKey` + 隐藏消息窗(`WM_HOTKEY`) | 不靠定时器、不读按键状态, 由 Windows 通知; 游戏挤定时器也不影响 |
| 按键轮询(兜底) | `user32.GetAsyncKeyState`(20ms) | 能区分左右 Shift; 可在菜单里关掉(于是完全不查按键状态) |

轮询通道的触发只看两个键的**当前按下位 | 自上次查询以来按过位** ——
所以**一直按着 W 等其它键照样能触发**, 而且即使定时器被游戏挤得慢了几百毫秒也不会漏按
(旧写法只判"当前是否按住", 会漏 —— 2026-10-07 修的)。按住不放只触发一次。
**不拦截按键**(游戏仍会收到该键), 建议绑游戏里没功能的键。

菜单 **「快捷键(&K)」**: 「快捷键设置…」对话框(每个动作一行: 修饰键 + 按键, 立刻生效并存盘,
并显示系统热键是否注册成功/被别的程序占用)、「同时使用按键轮询」勾选项、「恢复默认快捷键」。
设置存 QSettings(`hotkey_<动作>` / `hotkey_poll`)。
每次触发写入 `data/route_tester.log`(会标明是系统热键还是轮询触发的)。

**反作弊**: 只使用上述两个官方 API(后者可关掉) —— 不装键盘钩子、不注入按键、
不碰游戏进程/内存、不读写游戏文件, 也不是游戏进程的一部分。

## 9.5 提示音

| 动作 | 默认音效(Windows 自带) |
|---|---|
| 开始录制 | `Speech On.wav` |
| 结束录制 | `Speech Off.wav` |
| 标记位置 | `Windows Balloon.wav` |
| 错误提示 | `Windows Critical Stop.wav` |

菜单「音效」: 一键开关提示音 + 「音效设置」对话框(音量 0~100%、每个动作可换本地 .wav、
带试听与恢复默认), 设置存 QSettings(`sound_enabled` / `sound_volume` / `sound_file_<动作>`)。
**音量靠重采样**: Windows 的 waveaudio 驱动不支持 MCI `setaudio volume`(实测报 261),
而 `waveOutSetVolume` 会改整个系统音量, 所以改成"把 16 位 PCM 样本乘系数后写成临时 WAV
再播"(按 文件+音量 缓存于 `%TEMP%\WTRouteTester_sound\`)。

## 10. 打包与图标

```powershell
.\build_route_tester.ps1              # 默认: 只出 onedir 目录版(推荐)
.\build_route_tester.ps1 -OneFile     # 需要多版本分发时才加
```

- 产物: `dist\WTRouteTester\WTRouteTester.exe`(目录版整份拷走);
- **用户数据保护**: 重建会清掉 `dist\WTRouteTester`, 脚本先把 `data\` 暂存到 `dist\_data_backup`
  再在完成后搬回(录制的 `routes.json` + `maps\` 缓存不会丢);
- 精简 Qt 体积时**保留 jpeg/webp 图片插件**(地图是 JPEG);
- **图标**: `icon\icon_512X512_WTRouteTester.png`(AI 画的原图)→
  `tools\make_app_icon.py` 转成多尺寸 `icon\WTRouteTester.ico`(16/24/32/48/64/128/256,
  128 及以下 BMP 帧 + 256 PNG 帧;纯 Python, 不依赖 Pillow —— 本环境没装 Pillow,
  而 PyInstaller 用 `--icon x.png` 需要它);
  打包用 `--icon icon\WTRouteTester.ico`, 窗口/任务栏图标在运行时用同一张 PNG
  (`route_tester.py` 里 `setWindowIcon`, PNG 随 `--add-data` 单独打进去)。
  **改了图标只需重跑 `tools\make_app_icon.py` 再打包。**
  ⚠️ 根目录 `app.ico` + `icon\2.0\` + `tools\png_to_ico.py` 属于**黑名单主程序**, 不要混用。

- ⏳ **录像解析**(自动从录像生成线路)—— 调研结论与计划见 [`录像解析调研.md`](录像解析调研.md);

  目前没有缓存该数据(录像解析时要用)。
