# 8111 自定义对局实测分析(2026-08-12)

基于探针脚本实测"机库 → 自定义对局(击杀 bot + 自爆) → 退出"全程 64 帧数据,
分析自定义对局中 8111 各端点暴露的信息, 用于黑名单工具的进出场判定与昵称收集。

## 1. 进出场信号(叠加层显示/隐藏的关键)

| 状态 | `map_info.json` | `mission.json` |
|---|---|---|
| 机库/大厅 | `{"valid": false}` | `status: "running"` |
| 对局/地图中 | 完整地图数据 `{grid_size, grid_zero, map_max, map_min, hud_type, map_generation, valid: true}` | `status: "running"`, `objectives` 有/无 |
| 退出后回机库 | `{"valid": false}` | `status: "running"`(不变!) |

**结论**:
- `mission.json` 的 `status` 在机库/对局/退出后**始终是 "running"**, 不可用于进出场判断
- `map_info.json` 是否包含完整地图数据(`valid` 非 false 且有 grid/map 字段)是**唯一可靠的进出场信号**
- 黑名单工具对局判定应: `in_map = map_info 含地图数据` (已实现)

## 2. 击杀/伤害记录(`/hudmsg` 的 `damage` 数组)

```json
{"id": 4, "msg": "=AZUR2= 目击而道存矣 (435 工程) 击毁了 哲生 (M2A2)",
 "sender": "", "enemy": false, "mode": "", "time": 142}
```

消息格式(玩家确认):
```
<[联队=XXX= ]昵称> (<载具>) 击毁了 <[联队=XXX= ]昵称> (<载具>)   # 击杀
<[联队=XXX= ]昵称> (<载具>) 已被摧毁                            # 自毁/被摧毁
```

- `=AZUR2=` = 联队(战队)名称前缀(有联队才有);`哲生` = bot 名(无联队故无前缀)
- `(435 工程)` / `(M2A2)` = 载具名
- `⋇` = 主机平台玩家的标记(主机玩家昵称前有;PC 玩家无)
- `parse_hudmsg_names` 已能正确提取昵称: 例 `['目击而道存矣', '哲生']`

**结论**: 自定义对局中可通过击杀记录的 `msg` 提取击杀者与被击杀者昵称, 供黑名单比对。

## 3. 发言记录(`/gamechat`)

```json
[{"id": 70, "msg": "hahaha", "sender": "pecusgaming", "enemy": false, "mode": "All"}]
```

- `sender` = 发言玩家昵称(`gamechat` 的 `sender` 字段即玩家昵称)
- `msg` = 发言内容
- 黑名单工具用 `sender` 收集昵称; 发言昵称是否带联队前缀/`⋇` 需实测确认

**实测(2026-08-12, 自定义对局发言 2 条)**:
- `gamechat.sender` = **纯昵称(无联队前缀)**, 如 `目击而道存矣`
- `msg` 内容完整保留(如 "测试消息,仅友方可见")
- 因此黑名单通过 `sender` 收集的昵称与名单(纯昵称)直接可比对, 无需额外清洗

### 昵称格式规则(玩家确认, 击杀消息 `msg` 与发言 `sender` 通用)

```
<[联队=XXX= ][⋇ ]昵称> (<载具>) 击毁了 <[联队=XXX= ][⋇ ]昵称> (<载具>)
```
- `=XXX=` = 联队名(有联队才有); `⋇` = 主机平台玩家标记(在联队名与昵称之间, 无联队时在昵称最前); 两者均不是昵称的一部分
- `parse_hudmsg_names` 已验证可正确提取纯昵称(主机/PC、有/无联队、单/多词昵称均通过)

## 4. 其他端点

- `map_obj.json`: 自定义 bot 对局中**无玩家对象**(返回 `[]` 或仅有 `airfield` 标记)→ 8111 无法直接获取所有玩家列表/位置
- `gamechat` 在纯 bot 对局无聊天(需有人发言才有数据)
- `state` 陆战返回 `{"valid": false}`(空战仪表数据, 陆战不适用)
- `indicators` 在陆战返回 20 个陆战仪表键(rpm/gear/army/stabilizer 等)

## 5. 对黑名单工具的结论

- 进出场判定: 以 `map_info` 地图数据为准 (已实现, 本实测验证通过)
- 昵称收集: 击杀记录(`hudmsg.damage.msg`) + 发言记录(`gamechat.sender`) 均可, 逐步积累
- 自定义对局、试车场、正常对局均适用以上信号
