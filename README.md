# 战争雷霆黑名单助手 (WTBlackList)

基于战争雷霆官方 **8111 本地接口** 的陆战黑名单辅助工具: 手动维护黑名单,自动在每一局中收集玩家昵称,一旦发现黑名单玩家进入对局立即提醒。

> ⚠️ **测试阶段**: 当前版本处于测试阶段, 功能与数据格式可能调整, 请以本仓库正式发布说明为准。

## 功能

1. **黑名单表格**
   - 列: 条目ID / 玩家昵称 / **曾用昵称** / 玩家ID / 录像链接 / 原因 / 证据文件 / 事件发生日期 / 备注
   - 支持“添加条目 / 删除选中行”
   - **条目ID** 在填写完 **玩家ID** 与 **事件发生日期** 后自动生成, 格式 `玩家ID_当前时间`, 例如 `82351_20260808_14_23`, 全表唯一, 显示为小字
   - **事件发生日期**: 栏目前有 🕒 时钟按钮, 点击自动填入当前系统时间; 也可用日历+时间选择器手动选年月日时分
   - **原因** 下拉可选项:
     `TK(攻击核弹机)`、`TK(抢战区)`、`TK(被挤出掩体)`、`TK(使用空中单位击杀玩家地面载具)`、`TK(使用陆地单位击杀玩家空中载具)`、`种族仇恨言论`、`辱骂玩家`、`阻止玩家占领战区获得研发`、`其他原因`
   - 数据持久化到 `data/blacklist.json`

   **曾用昵称(自动维护)**: 软件仅在**通过玩家ID访问 WT Live** 时判断该玩家是否改过昵称, 若改过就把旧昵称自动加入“曾用昵称”栏(用户不可更改, 最多保存 **10 个**, 超出后删除最早的昵称); 当获取到的昵称与您填写的“玩家昵称”不一致时, 会在右侧昵称统计区下方**文字提醒**更新昵称(不弹窗)

2. **证据文件夹**
   - 点击“证据文件”列的文件夹图标, 在软件根目录 `evidences/` 下创建 `evidences/<玩家ID>/<条目ID>/` 并打开
   - 已存在则直接打开
   - 若尚未生成条目ID, 提示 `需要补充更多信息:"玩家ID"与"事件发生日期"`

3. **对局监控与黑名单发现**
   - 通过 8111 的 `/gamechat`(发言记录)与 `/hudmsg`(击杀列表)逐步收集当前对局玩家昵称(主机玩家昵称前的 `⋇` 标记会自动去除)
   - 通过 `https://live.warthunder.com/user/<玩家ID>/` 抓取黑名单各玩家的昵称
   - 一旦当前对局出现黑名单玩家 → 屏幕叠加层提示 `发现肃反人员: 昵称`(同一玩家每局只提示一次)
   - **对局开始/结束检测**: 8111 端口**没有**对局开始/结束的主动通知, 只能轮询推断。程序以 `/mission.json` 的 `valid` 字段为主(退出对局回机库后为 `false`)、辅以 `status`+`objectives` 组合判断, 并对"结束"做连续 3 秒确认, 避免退出对局后叠加层仍残留 `发现肃反人员`

4. **屏幕叠加层**
   - 检测到黑名单玩家时, 在屏幕 4/5(从上往下)位置显示 `发现肃反人员:` 及所有命中昵称; 未命中时显示 `正在确认名单中...`; 仅在进入对局时显示, 离开对局自动隐藏
   - 叠加层为**外部独立透明置顶窗口**(不注入游戏进程), 需游戏使用**全屏窗口(无边框)**模式才能显示在游戏之上
   - 工具栏「⚙ 叠加层设置」可在主界面调整: 水平位置(X%)、垂直位置(Y%)、**锁定位置**、背景颜色、背景不透明度、字体大小、**字体、字体颜色、背景圆角弧度**, 改动实时生效并保存到 `data/config.json`, 适配不同屏幕

5. **WT Live 访问检测**
   - 点击"检测"按钮**手动**检测 `live.warthunder.com` 访问流畅度(该服务器在国外, 决定黑名单查询效率)
   - 访问缓慢/不可达时界面提示并提醒**开启游戏加速器**
   - 主界面显示 **WT Live 访问(本次)次数**, 统计本次运行软件实际访问 WT Live 的次数(缓存命中的昵称不会重复计次), **关闭软件自动清零**
   - **访问策略(反爬友好)**: 复用 HTTP 连接(keep-alive)减少握手; 两次抓取间隔随机化(0.5~1.5s); 区分不同失败——`404`(无效ID)缓存 **7 天**不反复重试、`429`(被限流)立即停止整批、网络错误/5xx 冷却 **10 分钟**; 连续 3 次失败判定 WT Live 不可达并中止整批; 整批最长 **30 秒**超时自动停止; 抓取时状态栏显示进度(如"正在抓取 3/15")

6. **昵称缓存窗口**
   - 工具栏「🗄 昵称缓存」打开缓存查看窗口, 可看到**哪些玩家ID对应了哪个昵称**以及**缓存还有多久失效**
   - 缓存为**独立昵称缓存数据库**(`data/nickname_cache.json`), 与黑名单条目相互独立: 删除条目后缓存仍保留, 重新添加相同 ID 也能看到已缓存的昵称
   - 缓存有效期 24 小时, 失效后进入新对局会自动重新抓取; 命中缓存不访问 WT Live

7. **锁定条目 / 关于 / 单实例**
   - 「🔒 锁定条目」一键锁定所有条目的修改, 防止意外改动已编辑好的内容; 再次点击解锁; 锁定时“添加/删除”也会被禁用
   - 「ℹ 关于」弹出软件说明与作者信息(含作者 B 站主页链接)
   - **单实例**: 重复点击 exe 只会启动一份, 已运行时提示 “程序已在运行中”

## 安装

```bash
pip install -r requirements.txt
```

## 使用

1. 在战争雷霆中开启本地输出:
   设置 → 主要参数 → 对应战斗模式 → **允许远程访问 = 是**, 端口 **8111**
2. 运行程序:
   ```bash
   python main.py
   ```
3. 在表格中添加黑名单条目(填写玩家昵称/ID/原因等)
4. 进入游戏后, 程序自动检测新对局并开始收集昵称与比对

## 系统托盘

- 点击窗口关闭按钮“X”**不会退出程序**, 而是**最小化到系统托盘**(避免误关)
- 托盘图标**右键菜单**:
  - **启用/停用叠加层**: 开关屏幕叠加层的显示
  - **显示主界面**: 重新呼出主窗口(左键单击托盘图标也可)
  - **退出应用**: 真正退出程序

## 打包为 EXE(分发)

在项目根目录运行(使用项目内 `.venv`):

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

一键产出三种分发形态:

| 产物 | 说明 |
|---|---|
| `dist\WTBlackList\WTBlackList.exe` | **目录版**(onedir): 启动最快(免解压), 用于日常使用/绿色分发 |
| `dist\WTBlackList.zip` | **ZIP 版**: 解压即可运行 |
| `dist\WTBlackList_Setup.exe` | **自解压安装版**: 用户选安装位置(默认 `D:\Program Files\WTBlackList`, 无 D 盘或空间不足退回 `C:\Program Files\WTBlackList`), 装完自动在桌面建快捷方式 |
| `dist\WTBlackList_source.zip` | **源码版**: 完整源码(不含运行/构建产物), 可自行审查与二次开发 |

运行后会在可写目录自动创建 `data\blacklist.json` 与 `evidences\` 文件夹;
若安装到受保护的 Program Files 目录, 数据会自动改存到 `%LOCALAPPDATA%\WTBlackList`。
